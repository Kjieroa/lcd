# 🏃 Animacja Arduino LCD 16x2

## 📌 Opis projektu

Projekt przedstawia prostą animację wykonaną za pomocą **Arduino UNO** oraz wyświetlacza **LCD 16x2**.

Na ekranie wyświetlana jest animowana postać biegająca w górnym wierszu oraz przewijający się napis **„BIEGAMY PANOWIE”** w dolnym wierszu.

## ✨ Funkcje projektu

- 🏃 Animowana postać biegająca po wyświetlaczu.
- 📜 Przewijający się napis „MARSZ MARSZ MARSZ”.
- 🔄 Płynna animacja wykorzystująca funkcję `millis()`.
- 💡 Obsługa podświetlenia wyświetlacza LCD.
- ⚡ Odświeżanie animacji co 200 milisekund.

## 🧰 Wykorzystane komponenty

- **Przewody połączeniowe**
- **Biblioteka Adafruit LiquidCrystal**

## 💻 Wykorzystane technologie

- C++
- Arduino IDE
- Adafruit LiquidCrystal

## ⚙️ Jak uruchomić projekt?

1. Pobierz kod projektu z GitHuba.
2. Otwórz Arduino IDE.
3. Zainstaluj bibliotekę `Adafruit_LiquidCrystal`.
4. Podłącz wyświetlacz LCD do Arduino.
5. Wgraj kod na płytkę Arduino.
6. Gotowe! 🎉

## 🎬 Jak działa animacja?

**Górny wiersz:**
- Wyświetla animowaną postać.
- Postać zmienia wygląd podczas ruchu.

**Dolny wiersz:**
- Wyświetla przewijający się tekst.
- Napis: **MARSZ MARSZ MARSZ**.

Celem projektu jest nauka programowania Arduino, obsługi wyświetlaczy LCD, tworzenia własnych znaków oraz prostych animacji.
